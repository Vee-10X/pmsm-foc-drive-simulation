# Modelling and Performance Analysis of a Field-Oriented Controlled PMSM Drive

## Project Overview

This project focuses on the modelling and simulation of a Permanent Magnet Synchronous Motor (PMSM) drive using Field-Oriented Control (FOC) in MATLAB/Simulink. The model will incorporate speed and current control loops to regulate motor operation, and its performance will be evaluated under changes in speed reference and mechanical load.

## Aim

To develop a MATLAB/Simulink model of a Permanent Magnet Synchronous Motor drive using Field-Oriented Control and evaluate its performance under different operating conditions.

## Objectives

1. Develop a simulation model of a Permanent Magnet Synchronous Motor drive in MATLAB/Simulink.
2. Implement a Field-Oriented Control strategy for regulating the motor's speed and torque.
3. Design and integrate the required speed and current control loops using PI controllers.
4. Evaluate the motor's response to changes in speed reference and mechanical load.
5. Analyse key performance variables, including motor speed, electromagnetic torque, and d- and q-axis currents.
