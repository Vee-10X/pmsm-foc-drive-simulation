# PMSM Model Parameters

The PMSM used in this project is configured as a Wye-wound machine with constant d-axis and q-axis inductances and permanent magnet flux linkage.

| Parameter | Symbol | Value |
|---|---|---|
| Number of pole pairs | p | 6 |
| Permanent magnet flux linkage | λpm | 0.03 Wb |
| d-axis inductance | Ld | 0.00019 H |
| q-axis inductance | Lq | 0.00025 H |
| Stator resistance per phase | Rs | 0.013 Ω |
| Rotor inertia | J | 0.01 kg·m² |
| Rotor damping | B | 0 N·m·s/rad |

These parameters are used as the initial values for the simulation model.
